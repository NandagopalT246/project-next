# Project NEXT — AI-Native Brand Lifecycle Cockpit

A competition prototype (HUL TechTonic S8). A premium, cinematic "mission control"
cockpit that compresses a brand's response to a live opportunity from **~21 days to ~90 minutes**.

It demonstrates a thin, end-to-end thread across four stages:

**DISCOVER (COE) → DECIDE (BSC guardrail) → ACT (BAE ★) → LEARN (Brand Memory)**

## The three signature ideas (visible & felt)

1. **Time-to-Expiry** — every opportunity carries a live countdown whose value visibly
   decays (cool → amber → red) as the window closes.
2. **Pre-Flight Simulation** — before any human sees a draft, the AI stress-tests its **own**
   Option A, catches a flaw (broadcast-IP clash / opportunistic tone), and proposes a better Option C.
3. **Tiered Human Governance** — the AI never auto-publishes. Low/medium/high-risk actions route
   to different approval tiers; the demo exercises a Tier-2 one-click human approval.

Restraint is shown too: the Opportunity Queue is mostly MONITOR/IGNORE — only one card is ACT.

## Run it

```bash
npm install
npm run dev        # http://localhost:3000
```

Press **Run Demo** to play the deterministic 60-second sequence (identical every run — built for
clean screen recording).

> On this machine, Node is invoked directly (npm's scripts are policy-gated). The dev server is:
> `node.exe node_modules/next/dist/bin/next dev -p 3000`

## Reasoning brain (Gemini) + graceful fallback

The decision rationale, the AI self-critique, and the Option A → Option C rewrite are generated by
**Google Gemini** (`gemini-1.5-flash`) via the server route `src/app/api/reason/route.ts`.

- Add your key to `.env.local`: `GEMINI_API_KEY=your_key`
- **No key? A failed call?** The app runs the exact same scripted sequence via a hardcoded fallback,
  so the demo never breaks on camera. The provenance chip in the top bar reflects Gemini vs. scripted.

## Swap the brand

Everything reads from a single config object: **`src/config/brand.ts`** (brand name, moment,
signals, queue, scores, creative options, memory outcome). Edit that one file to re-skin the demo.

## Stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind v4 · Framer Motion.
Dark "Mission Control" design system; the amber→red ramp is reserved exclusively for Time-to-Expiry.

## Deploy (Vercel)

1. Push this folder to a Git repo.
2. Import into Vercel → framework auto-detected (Next.js).
3. Add the `GEMINI_API_KEY` environment variable in Vercel project settings.
4. Deploy. Confirm the public URL loads in an incognito window.
